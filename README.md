# LuckyRay LSH compatibility metadata

This repository contains signed compatibility metadata only. Official runtime
archives are downloaded directly from upstream. Discovery alone never grants
installation permission. Clients pin the production public key in the host.

No application source, runtime mirror, credentials or user data is published.
Existing LuckyRay v1.9.4 installers have no configured online update source.

Maintenance and withdrawal require a reviewed signed catalog.
